F-Pattern Content: Attention Decays Down the Page, So the Layout Should Too

The concept: eye-tracking studies show readers fully process the first entry on a scannable page — both a heading and its full excerpt, the two horizontal "bars" of an F — then read down the left edge scanning headings alone, barely touching anything on the right. This archetype builds the layout to match that real behavior instead of pretending every entry gets equal attention.

Entry 1 — full read
The only entry that gets both a heading and a complete excerpt

Entry two still earns a shorter excerpt

Attention has already started to decay, but not to zero — a single trimmed line still gets read.

Entry 2 — partial read

By entry three, only the heading is scanned

Entry 3 — heading only

When Not to Use This Archetype

Content where every entry is genuinely equally important — a numbered legal document, a set of parallel product tiers — should not have its later items artificially starved of attention. Use card-catalogue-index or feature-trio-grid instead, where every entry gets identical treatment on purpose.

Low-Attention Zone

Eye-tracking data shows this column gets almost no engagement. Never place a primary CTA, a key metric, or exclusive content here.
