Quad Chart: Layout-Factory Rollout Decision FOR REVIEW · 2026-07-24
Situation

Four Equal Boxes, One Fixed Order

The concept: unlike every size-hierarchy archetype in this catalog, a quad chart's four quadrants are exactly the same size on purpose. Reading order — not scale — carries the hierarchy: Situation always top-left, Ask always bottom-right.

Complication

When Not to Use This

Content with a genuine single most-important element should not be flattened into four equal boxes — use magazine-well or data-dense-report-grid instead, where size does the signaling work this format deliberately refuses.

Data

Fig. 1 — The Data quadrant is this format's one legal chart slot. A second chart elsewhere breaks the one-page-at-a-glance promise.

Ask
Adopt this archetype for any content that already has a fixed four-part narrative — situation, complication, evidence, recommendation — rather than forcing it onto a size-hierarchy layout.
Decision Memo: On-Call Rotation Change FOR DECISION · ENGINEERING LEADERSHIP
Situation

The current on-call rotation pages the same three senior engineers 80% of the time, while six other qualified engineers are rarely scheduled.

Complication

Two of the three most-paged engineers have raised burnout concerns in the last two retros; one is actively interviewing elsewhere.

Data

Rotation logs from the last two quarters confirm the imbalance is scheduling-driven, not skill-driven — all nine engineers have resolved comparable incident classes when actually paged.

Ask
Approve moving to a strict round-robin rotation across all nine qualified engineers, starting next sprint.

Vendor Selection: Observability Platform GO / NO-GO
Situation
  • Current tool's contract expires in 60 days
  • Three vendors evaluated over six weeks
Complication
  • Two finalists tie on core feature coverage
  • Pricing differs by roughly 40% at our scale
Data
  • Vendor A: 40% cheaper, 2-week migration
  • Vendor B: richer alerting, 6-week migration

Ask
