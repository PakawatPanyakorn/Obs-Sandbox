# Theme Summary Table

Index of every theme preset in this folder. Used by **List Mode** (print this table directly) and **Recommend Mode** (score candidates from this table before opening the top 3 full docs). Rows are generated only via Create Mode, Delete Mode, or the doc-backfill pass — never hand-edit a row out of sync with its preset's own `.md` doc.

Columns: **Aesthetic**/**Personality** are pulled straight from the theme's `design.aesthetic`/`design.personality[]` JSON fields. Both draw on a **closed vocabulary** — 9 aesthetics and 21 personality tags, defined in `shared-design-dna.md`. Never invent a term here or in a preset's JSON: the gallery turns every distinct tag into a filter chip, so a one-off word is a filter that matches exactly one theme. **Tone** is derived from background/color lightness (dark vs. light, colorful vs. colorless). **Best For**/**Avoid When** are one-line compressions of the theme's own doc — see `Doc` link for the full reasoning.
